# Chymanhaya

This repository contains the public GitHub Pages website for Chymanhaya.

It includes:

- `index.html` - app showcase and feature overview
- `privacy.html` - privacy policy for app store listings
- `terms.html` - terms and health disclaimer
- `support.html` - support and issue-reporting page
- `assets/` - images used by the website

To publish with GitHub Pages:

1. Open the repository on GitHub.
2. Go to `Settings > Pages`.
3. Set `Source` to `Deploy from a branch`.
4. Set `Branch` to `master` and folder to `/ (root)`.
5. Save.

Expected site URL:

https://auderhama.github.io/Chymanhaya/
